# 최종 제출 코드 검증 · 2026-11-17

## 변경 내용

기본 `main.py`가 최신 `12_1500`을 실행하도록 연결했다. 기존 A/B 엔진과 실험 파일은 보존했다. 최종 설정을 `src/final_dsp.py`로 분리하여 평가 노트북 및 `bench`, Clean 데이터에 대한 추론 의존성을 없앴다. 지역 PSD 추정, Wiener/LSA 25% 혼합, 다중 해상도·음성 복원 및 1.5 kHz 중심 감쇠의 계산은 기존 최고 후보와 같다.

샘플링 주파수가 다르면 내부적으로 16 kHz로 변환하고 복원하며, 채널별로 독립 처리한다. 4,096샘플 미만의 내부 신호는 끝값 패딩 후 잘라낸다. 무음은 그대로 반환한다. 입력과 같은 경로에 저장하는 실행은 파일 보호를 위해 거부한다. 출력은 기존 평가와 같은 PCM16이다.

## 실행 검증

- Python 3.12.14 / Linux의 새 가상환경에서 고정 패키지 설치 성공.
- `python -m pip check`: 의존성 충돌 없음.
- `main.py` 기본 명령으로 공개 Validation 164개 전부 처리 성공.
- 164개 모두 출력 파일명, 샘플링 주파수, 채널 수, 샘플 수 유지.
- 별도 평가 도구로 저장된 출력 WAV 164개 재평가, PESQ 실패 0건.
- 새 파일별 PESQ·SNR·STOI가 기존 `depth_round/validation_disk.csv`의 164개와 모두 일치. 최대 차이 0.0.
- 합성 신호에서 새 최종 DSP와 기존 `depth_round.estimate(x, '12_1500')`의 부동소수점 출력도 배열 원소별 동일.
- 자동 검사 4개 통과. 그중 CLI 입출력 검사는 한글 파일명, 대문자 `.WAV`, 8/16/22.05/44.1/48 kHz, 모노·스테레오, 0/1/17/1,023/4,097/5,001/7,003/48,000샘플 사례를 포함한다.
- 외부 작업 디렉터리 및 프로세스 병렬 실행을 확인했다.
- NaN 입력, 빈 입력 폴더, 입력=출력 폴더를 거부한다.
- 새 추론 import 경로에서 `bench`, `pandas`, `pesq`가 로드되지 않음을 검사했다.

검증 명령은 [README](../README.md)에 있으며, 실제 로그는 [io_checks.txt](../results/final_submission/io_checks.txt)에 보관한다.
