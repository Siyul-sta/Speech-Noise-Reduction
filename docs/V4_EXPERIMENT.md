# v4 실험 — Adaptive Noise PSD + 5% Dry Blend

## 목적과 기준

- 기존 **v3** 공식 히든 PESQ-WB: **1.88227067822995**.
- **v4 공식 히든 PESQ-WB는 아직 측정되지 않았음**. 아래 지표는 모두 공개 Validation의 대리 지표(proxy)로, PESQ 점수를 예측하거나 보장하지 않음.
- 기존 v3를 보존하면서 선택 가능한 `--method v4`를 추가함. **기본 실행은 계속 `--method b` (v3)**.

## 실험 방식

- 데이터: 제공된 Validation **164개 Noisy/Clean 음성 쌍**, 16 kHz.
- v3 기본 코드의 동일 STFT/ISTFT 구현 사용. ① 잡음 PSD 적응 속도, ② 원본 음성 비중, ③ Gain 평활화 설정을 실험함.
- **추론 입력: Noisy만 사용**. Clean은 SNR·STOI·로그 스펙트럼 거리 평가 전용.
- STOI 높을수록 좋음. LSD 낮을수록 좋음. SNR 높을수록 좋음.
- 배음 복원 강도 `harmonic_weight=2.0` 유지. 앞선 단독 HRNR 축소 실험에서 STOI/LSD 악화 관측.

## Validation 164개 결과

| 설정 | SNR(dB) ↑ | STOI ↑ | LSD(dB) ↓ |
|---|---:|---:|---:|
| v3 기본 | **14.382645** | 0.884139 | 10.421044 |
| adapt=0.01만 적용 | 14.245615 | 0.885692 | 10.103473 |
| dry_mix=0.05만 적용 | 14.320198 | 0.884846 | 9.938690 |
| **v4: adapt=0.01 + dry_mix=0.05** | 14.145536 | **0.886010** | **9.733045** |
| v4 + smooth_freq=0.5 | 14.148384 | 0.886144 | 9.733835 |

v4와 v3의 차이:
- SNR **−0.237108 dB**
- STOI **+0.001871**
- LSD **−0.687999 dB**
- v4가 v3보다 개선된 파일: STOI **112/164**, LSD **124/164**.
- 평활화 추가는 STOI를 0.000134 더 높였지만 LSD가 소폭 악화되고 복잡도가 늘어나므로 v4에서는 제외.

## v4 파라미터 (v3 대비 변경 두 가지)

```python
Config(harmonic_weight=2.0, adapt=0.01, dry_mix=0.05)
```

다른 파라미터는 모두 v3 기본값을 유지.

- `adapt=0.01`: 잡음으로 판단된 주파수 bin에서만 잡음 PSD를 느리게 갱신.
- `dry_mix=0.05`: 최종 STFT Gain에 원본 혼합 5%를 적용해 작은 음성 성분을 보존하는 실험.
- `harmonic_weight=2.0`: 기존 배음 보완을 유지.

## v4 명시 실행

```bash
pip install -r requirements.txt
python main.py --input input --output output_v4 --method v4
```

중요: `python main.py` 기본 실행은 아직 **v3**이므로, v4 제출 시 반드시 `--method v4`를 붙여야 함. 조교님 제출 방법이 `main.py` 기본 실행만 허용한다면 검증 후 최종 제출용 별도 커밋에서 기본을 v4로 바꿔야 함.

## 검증과 제한

- v3 코드의 엔진 함수를 고정된 v4 설정으로 재사용. 별도 학습이나 ML 없음.
- 16 kHz mono 테스트 파형에서 유한한 출력, 길이 보존, 원래 v3 함수에 동일한 설정을 넘겼을 때 일치함을 검증.
- 실제 PESQ-WB 계산은 실행 환경의 `pesq` 패키지 부재로 미측정.
- **STOI/LSD 개선이 히든 PESQ-WB 개선을 의미하지는 않음**. 오히려 SNR 감소 때문에 PESQ가 하락할 가능성도 있음.
- v4 설정은 위 Validation에서 탐색·선택했으므로 공개 Validation에서의 최적화 편향이 존재할 수 있음.
- 최종 제출 전에 CLI I/O 회귀 테스트와 조교 실행 규약 확인 필요.
